Data Analysis and Visualization Project using Microsoft Excel

<hr>

<h2>📌 Project Overview</h2>

<p>
This project demonstrates data analysis, Pivot Tables, dashboards, and visualizations using Microsoft Excel.
The dashboard was created using Superstore sales data to analyze sales performance, profit, quantity, customer segments, and product categories.
</p>
